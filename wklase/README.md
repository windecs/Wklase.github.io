# Wklase

Учебная платформа: ученики, учителя, администратор. Полностью статический сайт (HTML + CSS + JS), без сервера, без сборки, без платных сервисов. Данные хранятся в `localStorage` браузера или, по желанию, в вашем репозитории GitHub (см. раздел ниже).

## Возможности

- Вход по email и паролю. Публичной регистрации нет: пользователей создаёт администратор.
- Три роли с разными панелями:
  - **Ученик**: оценки, средний балл, домашние задания, расписание.
  - **Учитель**: выставление оценок, добавление домашних заданий.
  - **Администратор**: добавление, удаление пользователей, смена ролей и паролей, экспорт и импорт JSON.
- Языки LV / RU / EN, выпадающие меню, адаптивная вёрстка, встроенные SVG-иконки.

## Аккаунт по умолчанию

`admin@wklase.lv` / `admin123`

Сразу после первого входа создайте своего администратора, смените пароль и удалите стандартный аккаунт.

## Важно о безопасности

Это клиентское приложение. Без подключения GitHub данные лежат в браузере каждого посетителя и не синхронизируются между устройствами. Хэш пароля виден любому, кто открыл DevTools или файл данных, поэтому это **не** защита уровня реальной учебной системы. Для резервных копий и переноса на другое устройство используйте «Экспорт JSON» и «Импорт JSON» во вкладке «Резервная копия» админ-панели.

## Запуск локально

Откройте `index.html` в браузере. Или запустите `python3 -m http.server` в папке проекта и откройте http://localhost:8000.

## Публикация на GitHub Pages (бесплатно)

1. Зарегистрируйтесь на https://github.com (бесплатно).
2. Нажмите **New repository**, назовите его, например, `wklase`, оставьте **Public**, нажмите **Create repository**.
3. Загрузите файлы одним из способов:
   - Через сайт: на странице репозитория **uploading an existing file**, перетащите всё содержимое папки `wklase` (включая папки `css` и `js`), нажмите **Commit changes**.
   - Через git:
     ```bash
     cd wklase
     git init
     git add .
     git commit -m "Wklase"
     git branch -M main
     git remote add origin https://github.com/ВАШ_ЛОГИН/wklase.git
     git push -u origin main
     ```
4. В репозитории откройте **Settings → Pages**.
5. В разделе **Build and deployment** выберите **Source: Deploy from a branch**, ветка **main**, папка **/ (root)**, нажмите **Save**.
6. Через 1–2 минуты сайт будет доступен по адресу `https://ВАШ_ЛОГИН.github.io/wklase/`.

Все пути в проекте относительные, поэтому сайт работает в подпапке репозитория без дополнительных настроек.

## Хранение данных в GitHub

Данные можно хранить прямо в репозитории — в файле `data/db.json`, а вложения учителей в `data/files/`. Сервер не нужен.

**Как это работает**

- Сайт читает `data/db.json` из вашего репозитория (через GitHub API, запасной вариант — файл с самого сайта). Поэтому ученики и учителя на разных устройствах видят одни и те же данные.
- Записывать может только тот, у кого в браузере сохранён токен GitHub (админ и учителя). Ученики только читают, токен им не нужен.
- Репозиторий и ветка определяются автоматически по адресу `https://ЛОГИН.github.io/РЕПО/`. Для своего домена заполните `js/config.js`.

**Настройка (один раз)**

1. Опубликуйте сайт на GitHub Pages (см. выше). Репозиторий должен быть **Public**.
2. Создайте токен: GitHub → **Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token**. В **Repository access** выберите *Only select repositories* и ваш репозиторий. В **Permissions → Repository permissions** поставьте **Contents: Read and write**. Скопируйте токен (`github_pat_...`).
3. Войдите на сайт как админ, откройте вкладку **Резервная копия**, вставьте токен в блок «Хранение в GitHub», нажмите **Сохранить токен**, затем **Загрузить данные в GitHub**. В репозитории появится `data/db.json`.
4. Каждому учителю с правом записи нужно один раз вставить такой же токен (блок «Хранение в GitHub» внизу его кабинета). Токен хранится только в браузере этого человека.

После этого любое действие (новый пользователь, оценка, новость, задание) сохраняется коммитом в репозиторий.

**Ограничения, о которых нужно знать**

- **Данные публичны.** GitHub Pages на бесплатном тарифе работает только с публичными репозиториями, поэтому `data/db.json` (имена, email, оценки, хэши паролей) может прочитать любой, кто знает адрес репозитория. Хэши паролей защищены PBKDF2 с солью, но слабые пароли всё равно можно подобрать. Не используйте реальные персональные данные и не используйте пароли, которые вы применяете где-то ещё.
- **Токен даёт запись во весь репозиторий.** Любой, кто получил токен, может изменить `db.json` (в том числе роли и пароли). Выдавайте его только тем, кому доверяете, ограничивайте одним репозиторием и при необходимости отзывайте на странице токенов.
- **Вход проверяется в браузере**, поэтому это не замена настоящей системе авторизации.
- **Одновременная запись.** Если два человека сохраняют одновременно, второй увидит сообщение «Данные изменили в другом месте», страница обновится, и действие нужно повторить.
- **Обновление данных.** Страница перечитывает данные при входе, по кнопке «Обновить из GitHub» и раз в 3 минуты. Лимит GitHub для запросов без токена — 60 в час с одного IP.
- **Размер.** Файл данных до 1 МБ, вложения до 5 МБ каждое.
- Без токена и вне GitHub Pages сайт продолжает работать в локальном режиме (данные только в браузере), как раньше.

## Если нужен React + Vite + Tailwind

Этот проект намеренно сделан без сборки, чтобы его можно было просто залить на GitHub. Логика (`store.js`) и тексты (`i18n.js`) переносятся в React-компоненты без изменений.
